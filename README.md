Fire Emblem Fates UI edit mod

This mod changes the game's UI to make it a lot sillier, which in my opinion helps a lot to make the tone of the game more consistent with how crazy everything else about it is. Crucially, this mod does not obfuscate any gameplay information. I do not recommend running it for a first playthrough, but you technically could without hurting your understanding of the game mechanics.
This mod does not do any gameplay or dialogue modifications, it is strictly a sillier version of the UI.
It is compatible with both the Citra emulator or the Luma custom firmware (CFW) for modded 3DS consoles.


Installation:
Simply extract the romfs directory inside your relevant mod directory, with the titleID as its root. It should look like this:

[titleID]/romfs/m/@U

If you do not know what your game's titleID is, look bellow:

000400000012DE00: Fates Special Edition JPN -- 
000400000017A800: Fates Special Edition EUR --
0004000000179400: Birthright USA -- 
0004000000179500: Birthright EUR -- 
0004000000179600: Conquest USA -- 
0004000000179700: Conquest EUR -- 
0004000000179800: Fates Special Edition USA 

For instance, in order to mod my copy of the European special edition, my file architecture on Citra is:

/Citra/load/mods/000400000017A800/romfs/m/@U

On Luma, it would be: 

/luma/titles/000400000017A800/romfs/m/@U


If you are modding the game using Luma3DS, make sure to enable game patching through the setting menu (hold Select on boot)


Compatibility:

This mod is compatible with every mod that does not touch the same files. Importantly, it is compatible with UnassumingVenusaur's Gay Fates mod. In fact, she's even credited in the opening because I run this mod on my console and you should too.
